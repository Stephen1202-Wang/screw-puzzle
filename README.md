# 螺丝解谜（Screw Puzzle）

拧下螺丝 → 装进同色盒子 → 拆光层叠板块过关。共 999 关，层数从 2 层一路叠到 8 层。手机浏览器直接玩，**无广告、无内购、可离线**。

👉 **在线玩：** https://Stephen1202-Wang.github.io/screw-puzzle/

## 玩法

- 点螺丝即可拧下，飞进顶部**同色盒子**；盒子装满 3 颗就收走，换成新颜色。
- 颜色对不上的螺丝只能放进下方**临时孔位**——**孔位一被占满就算失败**。
- 螺丝只要被上层板块盖到**一点点**就点不动，必须先把压住它的板块拆掉。
- 某块板上的螺丝全部拆完，板块自动掉落，露出下层螺丝。

道具全部免费常驻：无限撤销、每关 2 次加孔位、重玩、以及**回退到还能通关的一步**。

## 关卡是怎么生成的

每关随机生成后要过两道闸门才会发给玩家：

1. **有解证明** —— 一个与游戏规则逐条一致的纯逻辑模拟器（单局约 0.08ms）做随机重启搜索，必须找到一条完整通关线，这条线会随关卡一起存下来。找不到就丢弃这个盒子队列重来。
2. **不平凡证明** —— 三种笨策略（贪心 / 看队列 / 随机乱点）必须全部失败，否则说明照直觉点就能过，弃用。

难度主要来自**打散盒子队列**（不让它跟着"自然拆解顺序"走）、**颜色数大于盒子数**（最高 14 色 vs 3 个盒子）、**更深的层叠遮挡**，以及**孔位有效容量 = 孔位数 − 1**。

实测：第 16 关以后贪心策略通关率 0%，而 150 关逐关把存下的通关线在真实引擎里重放，150/150 全部通关。
